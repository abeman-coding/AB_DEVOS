# AB_devos — Abebe Manaye Portfolio

This portfolio uses plain HTML, CSS, and JavaScript. It does not need Node.js, npm, React, or Next.js.

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click `index.html` to open it in a browser, or use VS Code Live Server.

## Add your profile photo
Copy your photo into the `images` folder and name it exactly `abebe.jpg`. The page uses:
`images/abebe.jpg`

If the photo is missing, a simple AB_devos fallback badge is shown.

## Customize
- `index.html`: biography, project details, social URLs and contact information.
- `style.css`: colors, layout, responsive design and animations.
- `script.js`: menu, theme switch, reveal animations, pointer tilt and welcome button.
- Replace sample LinkedIn, Instagram, Facebook, TikTok, and GitHub links with your actual profile links.
- Telegram is set to `https://t.me/theButcher_0`.

The orb/photo effects are made with CSS and JavaScript, not a real Three.js/WebGL model. The icon library and Google Fonts need an internet connection.
